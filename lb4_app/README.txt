Для использования данного приложения введите в поле "Значение" целое число(оно обозначает количество чисел при заполнении случайными), далее введите число в поле "Индекс"(оно обозначает максимальное число при заполнении случайными).
Далее или вставляете числа по индексу, или заполняете случайными числами при нажатии на кнопку "Случайные".
